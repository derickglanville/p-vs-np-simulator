LEARNING CENTER

What experiments can—and cannot—tell us.

P and NP

P contains decision problems solvable in polynomial time. NP contains problems whose proposed solutions can be verified in polynomial time. Whether P equals NP remains open.

NP-completeness

An NP-complete problem is in NP and every NP problem can be reduced to it in polynomial time. A polynomial-time algorithm for one NP-complete problem would prove P = NP.

Polynomial, exponential, and pseudopolynomial time

Polynomial functions such as n² grow far more slowly than 2ⁿ. O(nT) for Subset Sum is pseudopolynomial because T's binary representation has only O(log T) bits.

Worst case versus average case

Worst-case analysis studies the hardest input of each size. Average-case claims require a precisely specified probability distribution. Easy samples do not eliminate hard inputs.

Why testing cannot prove P ≠ NP

A benchmark covers finitely many inputs and specific implementations. A mathematical proof must cover an unbounded family under a rigorous model of computation.
